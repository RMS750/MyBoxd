MYBOXD MyBoxd — MAC

UPGRADING YOUR CURRENT MyBoxd INSTALL
1. Stop the old MyBoxd window with Control+C if it is still running.
2. Open Terminal and cd into this MyBoxd MyBoxd folder.
3. Run: bash UPGRADE_FROM_MyBoxd4.sh
4. The script preserves your account/database/TMDB configuration, downloads the
   official MovieLens 32M archive directly from GroupLens, imports the local
   catalogue, runs migrations/tests, and builds the frontend.
5. Run: bash start_local.sh

FRESH INSTALL
1. Run: open -e .env
2. Put your TMDB v3 API key after TMDB_API_KEY= and save.
3. Run: bash setup_local.sh
4. Run: bash start_local.sh
5. Create an account and import your Letterboxd ZIP.

NOTE ABOUT MOVIELENS
The raw GroupLens archive is intentionally NOT redistributed inside this MyBoxd
ZIP. setup_local.sh downloads ml-32m.zip directly from GroupLens to
backend/data/ml-32m.zip on your computer, then imports it into SQLite.
